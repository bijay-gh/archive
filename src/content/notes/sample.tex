\section{Introduction}
Welcome to the LaTeX demonstration note. This file shows how you can write `.tex` files that compile into standard Astro pages using KaTeX for mathematical notation, custom regex transformations, and custom layout tags.

\section{Hyperlinks and Page Connections}
You can link to external sites or local routes in two ways:

1. **Standard Hyperlink:** Use the standard LaTeX `\href{url}{text}` macro. For example, you can visit the \href{https://astro.build}{Astro Framework Website} or navigate back to the \href{/notes/gpu_architecture}{GPU Architecture Note}.
2. **Subpage Connections:** To highlight a child note or a deep dive, use the custom `\subpage{slug}{label}` command, which renders a premium callout link:
   
\subpage{gpu_main/pre_gpu_era}{Deep Dive: The Pre-GPU Era}

\section{Embedding Images}
Images can be placed using standard LaTeX `figure` blocks or floating macros:

1. **Standard Figure Block:** Use the `figure` environment with `\includegraphics` and `\caption`:

\begin{figure}[h]
\includegraphics[width=100\textwidth]{/media/notes/gpu/visiontek_geforce_256.jpg}
\caption{The GeForce 256, NVIDIA's first GPU}
\end{figure}

2. **Custom Layouts:** Use `\imageleft`, `\imageright`, or `\imagecenter` macros, which take three arguments: `{src}{width}{caption}`. For example:
   - `\imageright{/media/notes/gpu/visiontek_geforce_256.jpg}{0.35}{Float right image}`
   - `\imagecenter{/media/notes/gpu/visiontek_geforce_256.jpg}{0.5}{Centered image}`

Follow the command with `\clearfloat` if you want to clear any floats.

\section{Creating Tables}
You can render tables using the LaTeX `tabular` environment. We support alignment specifiers (like `l` for left, `c` for center, and `r` for right). The cells are separated by `&`, and rows are separated by `\\`:

\begin{tabular}{|l|c|r|}
\hline
Architecture & Compute Cores & Launch Precision \\
\hline
NVIDIA Ampere & 10496 CUDA Cores & FP16 and FP32 \\
NVIDIA Hopper & 144 SMs / Tensor Cores & FP8 and FP16 \\
NVIDIA Blackwell & Dual-Die / Cores & FP4 and FP8 \\
\hline
\end{tabular}

\section{Mathematical Equations (KaTeX)}
Inline math like $E = mc^2$ and display math both render beautifully. Here is an example of display math:

\[
f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2 \pi i x \xi} d\xi
\]
